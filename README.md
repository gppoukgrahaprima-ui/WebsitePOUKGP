# POUK Graha Prima

Website resmi POUK Graha Prima berbasis Next.js dan siap digunakan pada lingkungan production.

## Menjalankan secara lokal

```bash
npm install
npm run dev
```

Buka `http://localhost:3000` pada browser.

## Build production

```bash
npm run build
npm run start
```

## Deploy ke Vercel

1. Upload seluruh isi proyek ke repository GitHub.
2. Hubungkan repository tersebut ke Vercel.
3. Gunakan framework preset **Next.js**.
4. Build command: `npm run build`.
5. Install command: `npm install`.
6. Deploy proyek dan hubungkan domain production.

Konten gambar, galeri, warta, QRIS, dan struktur pelayanan diambil dari folder publik yang telah dikonfigurasi pada aplikasi.
